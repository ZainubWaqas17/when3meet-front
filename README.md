When3meet is a web-based application that works similarly to when2meet. It allows different people to find time to meet with each other for various purposes through letting event organizers to clearly see the available time slots of every participant. When3meet allows users to fill in their availability either manually or through importing it from the user’s Google Calendar, which is its key feature. It is mainly intended to be used by PC users who need to routinely meet with a group of people. We have not provided a mobile version of the application nor tested it on deployment yet.
